# Smarther Teste

Solução completa do teste técnico para a **Smarthis**, contendo 9 questões algumas de logica e outras resolvidas em Python.

## Sobre o Projeto

Este repositório contém as resoluções dos desafios propostos no processo seletivo, abordando desde raciocínio lógico até implementação de algoritmos e regras de negócio.

## Tecnologias

- Python 3.x
- Apenas bibliotecas padrão (`random`)
