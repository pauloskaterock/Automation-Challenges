# Exercico 2

Um quebra-cabeça, abaixo figurado, consiste em transferir os discos do 1º para o 3º
pino sob as seguintes regras:

1) Somente um disco pode ser transferido de cada vez de um pino para qualquer outro.
2) Nunca se deve colocar um disco maior sobre um disco menor.
Na transferência de 7 discos, utilizando-se os 3 pinos, obtivemos a tabela na imagem
abaixo.
Qual o número de movimentos necessários para transpor 10 discos do 1 para o 3 pino?
a. 511
b. 512
c. 1023
d. 1024
e. 1025

Resposta = C 1023
